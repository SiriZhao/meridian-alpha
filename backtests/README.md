# Backtests and walk-forward validation

This directory intentionally contains no performance claim or synthetic return
curve. A valid backtest must use point-in-time data, transaction costs, slippage,
turnover, drawdown, volatility, Sharpe, Sortino, beta/alpha vs SPY, exposure,
and concentration. It must use walk-forward evaluation and record/replay LLM
research fixtures. Any detected look-ahead leakage invalidates the result.
