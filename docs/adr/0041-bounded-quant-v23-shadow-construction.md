# ADR 0041 — Bounded V2.3 shadow construction and public evidence separation

Status: accepted for research implementation, financial validation pending.

Keep V2.2 signal and execution engine frozen. Compose bounded covariance / risk
budget / transaction-cost preference objectives through an opt-in subclass of
the existing chronological runner. The resulting typed packet is SHADOW_ONLY,
expected return and confidence are null, and no paper/live authority exists.

New public receipts capture source bytes, retrieval, adjusted-close fields and
events. Historical availability is always null. They support retrospective
descriptive references in a separate evidence lane, never historical PIT or
execution certification. They do not change the live bridge's stricter gates.

Hard risk limits, original order planning, reconciliation, canonical persistence
and original archived experiment identities remain unchanged. Use the existing
V1/V2.2 entry points to roll back. Real financial evaluation requires external
qualified evidence, not stronger engineering labels.
